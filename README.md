## timer

a simple countdown based timer that takes in an amount of time in seconds and rings the terminal bell forever after it has slept for that amount of time.
i made it because i wanted a timer that would wake me up from my nap with the terminal bell.
---

## usage 

```
./timer 60      #this will set a timer for 60 seconds
./timer         #this will set a timer for 2 seconds
```

--- 

## set up

```
gcc timer.c -o timer  #that's all
```
